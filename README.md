# 🛒 Market Basket Analysis Streamlit App

A powerful, user-friendly Streamlit web app that performs Market Basket Analysis using both the **Apriori** and **FP-Growth** algorithms.

## 📌 Features

✅ Upload your own transaction dataset (Excel format)  
✅ Choose between **Apriori** or **FP-Growth** algorithms  
✅ Supports **Arabic to English item translation**  
✅ Interactive support chart for frequent itemsets  
✅ Filterable and downloadable **association rules**  
✅ Enhanced **network graph** showing rule relationships  
✅ Clean UI with tabbed layout and visual insights  
✅ Built with: `Streamlit`, `mlxtend`, `matplotlib`, `networkx`, `pandas`

---

## 📊 What It Does

This tool helps you discover relationships between items in transactional data. You can analyze what products are often bought together and generate actionable association rules.
